React Native redesign · concept

FietsRouten, reborn

Two visual directions for the same cross-platform app — a React Native UI over a thin Kotlin native layer (GPS, speed, background location) and React Native Navigation. Both cover the full flow: search, route summary, knooppunten planner, turn-by-turn, layers & POIs, saved routes and settings. Compare the home screens first (1a vs 1b), then scroll for the build plan.

PLAN

The build plan

React Native owns the whole UI and app logic. Kotlin shrinks to a thin set of native modules for what JS can't do accurately — fused GPS, speed, heading, and background location during navigation. The self-hosted backend (GraphHopper, Nominatim, POI service) and OpenFreeMap / Overpass are reused unchanged.

Architecture — four layers
React Native UI
8 screens · React Native Navigation (native stack & tabs) @gorhom/bottom-sheet · Reanimated Zustand store (ex-MapViewModel)
Cross-platform JS
@maplibre/maplibre-react-native (map render) NavigationEngine.ts (ported from Kotlin) axios + React Query · TanStack react-native-mmkv (saved routes)
Kotlin native (thin)
LocationModule · FusedLocationProvider (GPS, speed, bearing) NavForegroundService (background location + notification) TTS / keep-awake / permissions bridges
Backend (reused)
GraphHopper · routing Nominatim · geocoding POI service OpenFreeMap · tiles Overpass · overlays
Kotlin → React Native migration map

What each current Kotlin piece becomes.

MapFragment / activity_main→React Native Navigation screens + native tab bar
MapViewModel (StateFlow)→Zustand store + React Query for async
MapLibre (Android SDK)→@maplibre/maplibre-react-native (same style URLs)
Retrofit APIs (GraphHopper…)→axios clients, identical endpoints & models
NavigationEngine.kt (snap/off-route)→NavigationEngine.ts — pure JS port, unit-tested
FusedLocation + speed + bearing→stays native — Kotlin LocationModule (TurboModule)
Background location during nav→stays native — Kotlin foreground service
TextToSpeech (voice guidance)→react-native-tts (thin native fallback if needed)
Milestones
M0
Foundation · ~1 wk
RN project, React Native Navigation shell, CI, design tokens, TurboModule scaffolding.
M1
Map & location · ~1–2 wk
MapLibre map, OpenFreeMap style, Kotlin LocationModule (GPS/speed/bearing), live puck & recenter.
M2
Search & routing · ~1–2 wk
Nominatim autocomplete, from/to, GraphHopper routing, route drawn on map.
M3
Route summary · ~1 wk
Profiles (Fiets/MTB/Race), distance/time, elevation chart, bottom sheet.
M4
Turn-by-turn nav · ~2 wk · the hard one
NavigationEngine.ts, foreground service + background location, off-route recalc, TTS voice.
M5
Knooppunten planner · ~1–2 wk
Bundled knoopunten.geojson, tap-to-add nodes, leg distances, multi-waypoint route.
M6
Layers & POIs · ~1 wk
Overpass overlays, POI service along route, layer toggles, dark map.
M7
Saved routes & profile · ~1 wk · new
MMKV persistence, ride history, stats, settings screen.
M8
Polish, offline & store · ~1–2 wk
Offline tiles, battery/perf tuning, iOS parity pass, Play Store + TestFlight.
